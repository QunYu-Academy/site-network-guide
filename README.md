# 站群搭建指南

一家外贸公司想做德国站，该先在主站加一个德语栏目，还是单独建站？这本手册从这类业务选择讲起，帮你判断新站要服务谁、要准备哪些独有内容，以及收到询盘后由谁跟进。

[阅读《站群搭建指南》PDF（45 页）](./站群搭建指南.pdf)

## 带着一个建站想法来读

1. **先判断要不要建。** 第 10–13 页用市场、场景、产品线、品牌四种理由判断建站需求。挑一个你正在考虑的站，沿第 13 页的决策树走一遍。
2. **给这个站填一张任务卡。** 第 16 页有模板。把目标客户、客户最关心的问题、能提供的真实资料和询盘负责人写进去。想看填好的例子，翻到第 34–36 页的德国设备站或体育照明站。
3. **上线前亲手试一次。** 用第 42–43 页的检查表过一遍，提交一条测试询盘，确认负责人能收到，也能看出客户来自哪个站、哪个页面。
4. **已有多个站，直接看第 28–29 页。** 把各站的投入、有效询盘和成交情况放在一起，决定哪些值得继续投入，哪些适合合并。

要动手选域名或规划内容，可查第 17–20 页。准备让 AI 辅助建站时，第 32–33 页给出了从任务卡到页面的流程和提示词示例。
